# Café Boyfriend 

A personal front-end web development project — a fictional "rent-a-companion" café concept site, built from scratch using HTML5 and CSS3.

---

##  Overview

During the beginning of my first year, I was tasked with designing and developing a simple website from scratch using HTML as part of a practical assignment. This project allowed me to build a strong foundation in front-end web development by applying core concepts such as page structure, styling, and layout.

Intrigued by the creative possibilities of web development, I went above and beyond the assignment requirements by applying custom CSS to craft an engaging, visually appealing user interface and deepen my understanding of web design principles.

---

##  Features

* **Multi-Page Navigation:** Consistent navbar across all pages for seamless navigation.
* **Themed Aesthetics:** Custom background imagery featuring a cherry blossom / Kyoto-inspired theme.
* **Pricing & Services:** Styled tables highlighting service packages and pricing tiers.
* **Interactive Menu:** Visual showcase of café items (coffee, tea, milkshakes, pastries).
* **User Authentication Mockup:** A styled login form interface.
* **Atmospheric Audio:** Integrated background audio player (`Cafemusic.mp3`).
* **Interactive Elements:** Custom hover effects and active-state styling for links and buttons.

---

##  Pages Overview

| Page | Description |
