**Café Boyfriend **
A personal front-end web development project — a fictional "rent-a-companion" café concept site, built from scratch using HTML and CSS.
**Description**
During the beginning of my first year, I was tasked with designing and developing a simple website from scratch using HTML as part of a practical assignment. This project allowed me to build a strong foundation in front-end web development by applying core concepts such as page structure, styling, and responsive design.
I was so intrigued with the concept of web development that I went above and beyond, applying CSS to create an engaging and visually appealing user interface while improving my understanding of web design principles.
**Features**
Multi-page site with a consistent navigation bar across all pages
Custom background imagery and a cherry blossom / Kyoto-inspired theme
Styled tables for service packages and pricing tiers
An interactive menu page showcasing café items with images
A login page with a styled form
Background audio player
Custom hover and active-state link styling
**Pages**
Page	Description
`MainMenu.html`	Homepage introducing the Café Boyfriend concept
`Menu.html`	Café menu items (coffee, tea, milkshakes, pastries)
`Login.html`	Account login page
`Packages.html`	Rent-a-Boyfriend service packages and pricing
`AboutUs.html`	About the concept, rules, and terms & conditions
**Tech Stack**
HTML5 – page structure and content
CSS3 – styling, layout, hover effects, and theming

Getting Started
Clone the repository:
```
   git clone https://github.com/your-username/cafe-boyfriend.git
   ```
Open `MainMenu.html` in your browser — no build tools or server required.
**Notes**
This is a first-year student project created for learning purposes and is not a functioning commercial service.
The login form is a front-end mockup and does not connect to a real authentication system.
